# Caydanlik Islik Ruh Analizi

Bu depo, evdeki caydanligin cikardigi isligi **resmi bir devlet protokolu ciddiyetinde** yorumlar.
Amacimiz insanliga hizmet degil; cayin kendini ifade etme hakki.

## Neden variz?

Cunku birisi durduk yere bir seye takildi. Takilan sey buydu.
Anlamli olmasi gerekmiyordu. Olmadi da.

## Kurulum

```bash
python3 analiz.py
```

Python 3 yeter. Baska hicbir sey gerekmez. Hatta bazen Python da gerekmez ama biz abartmiyoruz (abartiyoruz).

## Kullanim

1. Caydanligi koy.
2. Islik baslayinca kronometre tut (telefonun saat uygulamasi yeter, CERN lazim degil).
3. Program sorunca saniyeyi yaz.
4. Ruh raporunu oku.
5. Cayi ic.
